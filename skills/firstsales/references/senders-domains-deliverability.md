# Senders, domains and deliverability

A connector is a linked account: a mailbox that sends email, or a calendar tool. Mailboxes are connected in the app, not from the CLI. The CLI lists, tests and tunes them.

```bash
firstsales connectors list --org org_123 --workspace ws_123 --json
firstsales connectors test --connector conn_123 --org org_123 --workspace ws_123
firstsales warmup status --connector conn_123 --org org_123 --workspace ws_123 --json
firstsales connectors update-display-name --connector conn_123 --data '{"displayName":"Sam from Acme"}' --org org_123 --workspace ws_123
firstsales connectors update-sender-profile --connector conn_123 --data '{"title":"Founder","signatureEnabled":true}' --org org_123 --workspace ws_123
```

- `update-display-name` body: `displayName` (required).
- `update-sender-profile` takes any of `displayName`, `title`, `department`, `contactNumber`, `socialLinkedin`, `socialTwitter`, `socialWebsite`, `signature`, `signatureFields`, `signatureEnabled`.
- `update-settings` takes any of `sendingConfig`, `syncSettings`, `resetBackfillCursor`. It changes how a live mailbox sends, so show the change and get a yes.

## Booking links (Cal.com)

```bash
firstsales connectors create cal-com --event-type 12345 --org org_123 --workspace ws_123
```

- Needs `--event-type` or `--booking-url`.
- The Cal.com key is read only from the `FIRSTSALES_CAL_COM_API_KEY` environment variable. Ask the user to set it in their own shell. Never ask for the key, and never put it on the command line.

## Domains

```bash
firstsales email-auth status --org org_123 --workspace ws_123 --json
firstsales email-auth verify --domain acme.com --dkim-selector google --org org_123 --workspace ws_123
firstsales tracking-domains list --org org_123 --workspace ws_123 --json
firstsales tracking-domains create --data '{"domain":"track.acme.com"}' --org org_123 --workspace ws_123
firstsales tracking-domains verify --domain td_123 --org org_123 --workspace ws_123
```

- `email-auth status` shows SPF, DKIM and DMARC for the sending domains. `verify` checks them again after a DNS change.
- A tracking domain needs a DNS record before `verify` passes. DNS changes can take hours.

## Removing (confirm first)

- `connectors delete --connector conn_123 --confirm` unlinks a mailbox. Campaigns that send from it stop sending from it.
- `tracking-domains delete --domain td_123 --confirm` removes a tracking domain.

## Edge cases

- `connectors test` failing usually means the mailbox login expired. The user reconnects it in the app.
- A brand-new mailbox should warm up before it sends a full campaign. Check `warmup status` first.
