# Knowledge bases and offerings

The writer uses these to describe what the user sells. Good facts here mean better emails.

- A knowledge base is a set of pages about the company: website pages, docs, FAQs.
- An offering is one product or service, with its benefits.

```bash
firstsales kb list --org org_123 --workspace ws_123 --json
firstsales kb get --kb kb_123 --org org_123 --workspace ws_123 --json
firstsales kb create --data '{"name":"Acme site","websiteUrl":"https://acme.com","isDefault":true}' --org org_123 --workspace ws_123
firstsales kb add-sources --kb kb_123 --data '{"urls":["https://acme.com/pricing"]}' --org org_123 --workspace ws_123
firstsales kb query --kb kb_123 --data '{"question":"What does Acme charge?"}' --org org_123 --workspace ws_123
firstsales offerings list --org org_123 --workspace ws_123 --json
firstsales offerings create --data '{"type":"service","name":"Onboarding","information":"Two-week setup with a named engineer."}' --org org_123 --workspace ws_123
```

- `kb create` needs `name` and `isDefault`. Optional: `description`, `websiteUrl`.
- `kb update` takes any of `name`, `websiteUrl`, `isDefault`.
- `kb add-sources` takes `urls`, 1 to 100 per call. Pages are read in the background, so they show up after a short wait.
- `kb query` needs `question`. Use it to check what the writer will know.
- `offerings create` needs `type` (`product` or `service`), `name` (up to 100 characters) and `information`. Optional: `shortDescription`, `keyBenefits`, `url`.

## Deleting (confirm first)

`kb delete --kb kb_123 --confirm` and `offerings delete --offering off_123 --confirm` remove them. Campaigns that use them lose those facts. Ask first.

## Edge cases

- Pages that need a login, or that load only with JavaScript, may come back empty. Paste the facts into an offering instead.
