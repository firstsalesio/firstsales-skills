# Changelog and dashboard

## Dashboard

```bash
firstsales dashboard get --org org_123 --workspace ws_123 --json
```

One call for the workspace at a glance: the same numbers as the home page in the app. Start here when the user asks "how are we doing?".

## Changelog

```bash
firstsales changelog whats-new --org org_123 --workspace ws_123 --json
firstsales changelog whats-new --all --org org_123 --workspace ws_123 --json
firstsales changelog read --data '{"all":true}' --org org_123 --workspace ws_123
firstsales changelog react --slug signals-beta --data '{"reaction":"love"}' --org org_123 --workspace ws_123
firstsales changelog feedback --slug signals-beta --data '{"text":"Please add CSV export"}' --org org_123 --workspace ws_123
```

- `whats-new` shows notes the user has not read. `--all` shows every note.
- `read` marks notes as read: `{"all":true}` for every note, or `{"entryId":"..."}` for one. Send one of the two, never both. Do it only when the user asks.
- `react` takes `reaction`: `sad`, `meh`, `neutral`, `happy` or `love`.
- `feedback` sends `text` to the FirstSales team. Show the text and get a yes first.
