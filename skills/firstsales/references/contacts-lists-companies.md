# Contacts, lists, tags, imports, companies, suppression

## Contacts

```bash
firstsales contacts list --search jane --org org_123 --workspace ws_123 --json
firstsales contacts create --data '{"email":"alex@example.com","firstName":"Alex","listId":"list_123","source":"api"}' --idempotency-key row-001 --org org_123 --workspace ws_123
firstsales contacts update --contact contact_123 --data '{"title":"CTO"}' --org org_123 --workspace ws_123
firstsales contacts overview --contact contact_123 --org org_123 --workspace ws_123 --json
```

`contacts create` needs `email`, `listId` and `source` (a short label, up to 100 characters, such as `api`). Optional: `firstName`, `lastName`, `title`, `company`, `linkedinUrl`, `phone`, `timezone`, `customFields`, `tags`. `contacts list` filters: `--search`, `--status`, `--source`, `--tags`, `--company`, `--list-id`, `--verification-status`, `--mobile-only`, `--sort-by`, `--sort-order`.

`contacts delete` and `contacts merge` cannot be undone. Show the contact(s) to the user, get a yes, then pass `--confirm`.

## Lists

`contact-lists members --list list_123 --add contact_1 --remove contact_2` changes membership (body `add`, `remove`; the flags repeat). If the list feeds a running campaign, the API refuses unless you pass `--acknowledge-campaign-enrollment`. That flag enrolls people into live sends: ask first and name the campaign.

## Imports and exports

`contact-imports create` takes a `--data-file` body: `contacts` (rows shaped like `contacts create`), `listId` and `source` required, `tags` optional. `contact-exports list` shows past exports. `contact-fields list` shows custom field keys to use in `--data`.

## Companies

```bash
firstsales companies import --data-file companies.json --idempotency-key import-001 --org org_123 --workspace ws_123
firstsales companies duplicates --company company_123 --org org_123 --workspace ws_123 --json
```

`companies.json` is `{ "companies": [{ "name": "...", "domain": "..." }] }`, 1 to 10,000 rows. Turn a `name,domain` CSV into it:

```bash
jq -R -s '{companies: (split("\n") | .[1:] | map(select(length > 0) | split(",") | {name: .[0], domain: .[1]}))}' companies.csv > companies.json
```

The response gives `created`, `duplicates` and `errors` counts and lists only rows that failed. `companies merge` and `companies delete` are destructive.

## Suppression

`firstsales suppression check jane@example.com example.com` checks up to 100 addresses or domains and shows `value`, `suppressed` and `reason`. There is no list or export.
